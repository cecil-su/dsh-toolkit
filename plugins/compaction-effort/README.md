# Codex 压缩摘要推理档位

当 `openai-codex` 路由下任意模型生成上下文压缩摘要（`purpose: compaction`）时，如果请求未指定推理档位，或指定了 `off`、`none`，改为发送 `medium`。其他明确指定的档位原样传递。

仅按提供方和用途匹配，不按模型名称猜测。主对话、会话标题及其他提供方的请求均不变。规则作用于新请求，不重写历史轨迹。可在插件管理中停用以恢复原行为。

迁移：新包名为 `@local/compaction-effort`，不会自动替换已安装的旧包。若原先已安装旧包，请先卸载旧包，再安装此目录，避免同时注册两个相同用途的监听器。插件不持久化状态，无需迁移数据。
