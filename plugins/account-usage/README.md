# 账号额度

聊天输入框下方，原生上下文百分比右侧的 `7d 71%` 表示 **Codex 账号 7 天额度还剩 71%**（示例，实际随账号变化）。文字前的小圆环也表示同一剩余比例。点击圆环或 `7d`，卡片默认贴着按钮上方打开，上方空间不足时会换边或缩短卡片。卡片里可查看套餐实际提供的额度窗口、各自的本地重置时间和最近一次成功更新时间，也可以手动刷新。仅有周限额的账号不展示 5 小时窗口。再次点击额度按钮、点击外部或用 Tab 将焦点移到其他控件，卡片就会关闭。在卡片内按 Esc 会关闭卡片并把焦点还给额度按钮。`7d —` 表示没有有效的周读数，点开可查看状态。

- 这是 **ChatGPT 订阅账号的额度**，不是当前会话的 token 用量、API 余额或某个模型独有的配额。「周」指服务端返回的 7 天窗口，不按自然周推算。
- 先在 DSH 设置中登录 Codex。插件读取 DSH 已有的 Codex 授权，不使用 Pi 或 Codex CLI 的凭据，不替你登录、刷新令牌或修改配置。
- 额度请求只从 DSH Host 发往 ChatGPT 的只读用量地址。页面只接收状态、百分比和时间，不接收原始响应、账号标识或凭据。不会把额度写到会话历史。
- 页面可见且已连接时，通常每分钟更新。刷新中或同一账号暂时查询失败时，按钮保留仍可用的百分比，不添加「上次」后缀；点开可查看最近一次成功更新时间、刷新失败时间及何时会自动重试。在服务端要求等待时，手动刷新暂不可用。临时失败最多沿用采样后 15 分钟的读数；账号更换、授权失效或窗口重置时不沿用对应旧数。
- 以服务端返回的窗口时长为准，只显示套餐实际提供的额度；不把缺失值当作 0% 或 100%。一个窗口重置不影响另一个仍有效的读数。

## 安装

在 DSH 插件管理中添加本目录。该插件与 `codex-signin` 可独立启停；后者提供登录入口，不是查询依赖。
